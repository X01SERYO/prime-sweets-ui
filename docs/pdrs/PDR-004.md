# PDR-004 — Daily retail sale

**Status:** Proposal
**Language:** English
**Scope:** The **Detal** section and the main navigation.
**Document role:** What the seller does in the web client. Not a description of the running UI.

The business source of truth, including all decisions, is the Core API [PDR-004](../../../prime-sweets-api/docs/pdrs/PDR-004.md).

## 1. Purpose

Record over-the-counter retail sales of the day on a section separate from invoices and Cargue, and close the till (cierre de caja) for each day.

## 2. What the seller can do

1. Move between **Por mayor**, **Detal**, **Cargue**, and **Productos** from a persistent navigation (bottom bar on phone, sidebar on PC).
2. In **Detal → Hoy**, search a product in an inline list (no modal), select it, type the quantity, and press **+ Agregar**.
3. Edit a row's quantity or delete the row.
4. Read the retail total sold and total profit above and below the table.
5. See a warning tooltip on products without retail cost.
6. In **Detal → Días anteriores**, switch between **Sin revisar** (default) and **Revisados**, 10 per page.
7. In **Sin revisar** (today included once it has sales), select days, see their accumulated total sold and profit, and with one **Cerrar caja** mark all of them Revisado. It cannot be undone; a closed today accepts no more sales. Hoy has no review action.

## 3. What the UI does not decide

The API decides what "today" is, whether a day is editable, the prices, the totals, and which days are listed. The client shows what the API returns.

## 4. Out of scope

Invoices, customers, printing, cash counting, pending-review badges, editing a past day, product detail of past days, changing the date.

## 5. Acceptance criteria

- Columns: Código, Marca, Producto, Precio de venta detal unidad, Cantidad, and a delete action.
- Selecting a product does not add it; **+ Agregar** with a quantity ≥ 1 does.
- Totals are shown above and below the table and labelled as retail.
- Días anteriores uses the same pagination as Productos, 10 per page by default.
