# PDR-003 — Product administration

**Status:** Proposal
**Language:** English
**Scope:** The Productos entry on the home screen.
**Document role:** What the seller does in the web client. Not a description of the running UI.

The business source of truth is the Core API [PDR-003](../../../prime-sweets-api/docs/pdrs/PDR-003.md). This client does not call Alegra.

## 1. Purpose

From the home screen the seller opens **Productos** to create a product, update it, or retire it. The API keeps Alegra aligned. The button does not depend on the selected delivery day.

## 2. What the seller can do

1. Press **Productos**, to the left of **Nueva venta**.
2. Create a product.
3. In a table, edit the wholesale and retail cost and sale price, the units, and the pack. The screen shows a suggested sale price from the wholesale cost and a margin percent (15 by default), and the real margin of each channel. Those figures are references. The seller chooses the sale prices. The client sends only the fields that changed.
4. Retire a product. The product leaves the choices offered on a new sale. Sales that already include it stay as they are.

## 3. What the UI does not decide

The API validates the product, stores it, and talks to Alegra. The client sends the form and shows the result, including a failure that happened after the product was already saved.

## 4. Out of scope

- Entregas, Cargue, and the week. Those stay in [PDR-002](./PDR-002.md).
- Excel import and the Alegra inbound pull. Those are API operations with no screen in this feature.
- A direct browser call to Alegra.

## 5. Acceptance criteria

- **Productos** is on the home row, left of **Nueva venta**, on the phone and on the PC.
- Opening it does not require a delivery date.
- Create, update, and retire each call the API and show its result.
- The table shows code, name, brand, both costs, both sale prices, units, and pack. Suggested price and real margins are calculated. The margin percent defaults to 15 and is not stored.
- A save sends only the changed fields. `0` is saved. An empty field is not sent. Name and brand are not edited on this screen.
- A retired product is not offered when adding a line. An existing sale line is unchanged.
